🎯 Calibración del Sistema

¿Qué es la calibración?

El sistema aprende de tus correcciones. Cada vez que editas notas en el Piano Roll y las guardás como ejemplo, el sistema aprende tu patrón de afinación (ej: si tendés a cantar un poco más agudo o grave).

Esto NO re-entrena el modelo CREPE (eso requeriría GPU y muchos datos), pero aplica correcciones inteligentes basadas en tu historial.

❓ Ayuda - VOZ-A-COSA

🎤 ¿Cómo usar?

  1. Grabar: Presiona el botón rojo para grabar tu voz cantando, tarareando o silbando.
  2. Analizar: El sistema detecta automáticamente las notas. Podés corregir la tonalidad si es incorrecta.
  3. Editar: En la pestaña "Analizar" podés ver y editar las notas en el Piano Roll.
  4. Sintetizar: Elegí un instrumento y descargá el MIDI/WAV.

🎹 Instrumentos

VOZ-A-COSA incluye 8 instrumentos predefinidos usando síntesis wavetable y SoundFonts:

  • Piano Cálido: Piano acústico (SoundFont)
  • Synth Lead: Lead tipo 80s (Sawtooth)
  • Synth Pad: Pad atmosférico (Sine + Chorus)
  • Bass 808: Sub bass estilo trap
  • Pluck: Cuerda punteada (Karplus-Strong)
  • Cuerdas: Ensemble de cuerdas (SoundFont)
  • Flauta: Flauta traversa (SoundFont)
  • Órgano Rock: Hammond B3 (Additive)

🎼 Escalas soportadas

Mayor, Menor, Pentatónica, Blues, Modos (Dorian, Phrygian, etc.), y más.

💡 Tips para mejor detección

  • Canta notas claras y sostenidas (al menos 0.1 segundos)
  • Evita ruido de fondo
  • Usa auriculares si hay retroalimentación
  • Si la detección es incorrecta, cambia la escala/tonalidad manualmente
  • Usa el Piano Roll para corregir notas individuales
  • ¡Calibrá el sistema! Guardá ejemplos corregidos para mejorar la detección

🎯 Sistema de Calibración

VOZ-A-COSA aprende de tus correcciones:

  1. Grabá y corregí las notas en el Piano Roll
  2. Guardá como "Ejemplo de Calibración"
  3. Repetí 3-5 veces con diferentes melodías
  4. El sistema aprenderá tu patrón de afinación

🔧 Tecnología

CREPE (Convolutional Representation for Pitch Estimation) - Red neuronal CNN para detección de pitch con precisión de ~10 cents.
